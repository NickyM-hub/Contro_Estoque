# Contro_Estoque

O sistema de controle de estoque foi desenvolvido para auxiliar empresas na organização, gerenciamento e acompanhamento de produtos armazenados, proporcionando maior controle sobre entradas, saídas e disponibilidade de mercadorias.

A plataforma permite monitorar o estoque em tempo real, garantindo que os produtos estejam sempre atualizados no sistema. Entre suas principais funcionalidades, destaca-se o alerta automático de estoque mínimo, que notifica o usuário sempre que a quantidade de um produto estiver abaixo do limite definido, ajudando a evitar falta de mercadorias e prejuízos nas vendas.

Além disso, o sistema possui um mecanismo de segurança que bloqueia a venda de produtos indisponíveis ou inexistentes. Caso um produto tenha sido removido do sistema pelo administrador ou esteja sem estoque, a venda é automaticamente impedida, evitando erros operacionais e inconsistências no controle.
